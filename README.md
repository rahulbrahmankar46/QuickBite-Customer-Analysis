# QuickBite Customer Analysis
Customer analytics project using Python, Pandas, NumPy and data visualization

## Project Overview
An exploratory data analysis project focused on
understanding customer purchasing behaviour,
revenue contribution, delivery performance and
business opportunities.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Key Business Findings
- Analysed 2,000 customer records.
- Top 20% of customers contributed approximately
  60.61% of total revenue.
- Orders in the last 12 months showed a strong
  relationship with annual customer spending.
- Evaluated delivery performance and customer ratings.

## Project Files
- Jupyter Notebook: Complete analysis
- Original CSV: Source dataset
- Cleaned CSV: Processed dataset
- Executive Summary: Business recommendations
- Charts: Data visualisations

## How to Run
Install dependencies:

pip install -r requirements.txt

Open the notebook and run all cells.
